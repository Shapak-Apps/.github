# Hello

[Shapak-Apps][org site] is an open-source organization from Turkmenistan. We build software for people who speak Turkmen: language courses, translators, small tools, and apps for education and healthcare. Everything we release is free, has no ads, and works both offline and online.

Most of our contributors are students opening their first pull request. We split issues into small pieces and review code in Turkmen, so weak English is not a blocker here.

[org site]: <https://shapak-apps.github.io/>
